"# SIHoceammonitoringsystem" 
<br>
building blocks:
<br>
1. scrapper to pull data:

  - scrapper to extract news from social media and news
  - filter out the spam and fake news 
  - use a nlp transformer to extract useful info and geo tag it
2. Database to store news data:
3. api to send data to the html and js
4. website using html and js

Requirements:
- Python 3.8 or higher 
- modern web browser like chrome,edge and safari
- internet 

Installation:
- install pip 
- (optional) create a py venv to keep it simple 
- run this command in cmd in the folder: <br> 
pip install -r requirements.txt
- also install spacy nlp by : <br>
python -m spacy download en_core_web_sm
- you're all set ^_^
